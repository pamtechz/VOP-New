# Certificate Background Asset

The authoritative certificate background supplied for the VOP certificate editor is:

- Path: `/assets/certificate_bg.png`
- Canvas: **1513 × 1040 px**
- Base layer: the complete supplied VOP navy/gold border, honeycomb field, VOP seal and Seventh-day Adventist mark.
- The certificate template renders **above** this background.
- The background must not be recreated with CSS overlays or duplicated with additional seal/logo decorations.
- Certificate editor default zoom: **40%**.
- Certificate artboard: **1513 × 1040**.

The runtime/template contract must continue to use the single background URL stored in the authoritative certificate template.
